# Link utili

La configurazione locale `config/link-utili.json` sostituisce l'esempio distribuito.
Le schede sono ordinate per nome; `"inFondo": true` colloca una scheda dopo tutte le altre, preservando l'ordine alfabetico delle restanti.

`"immagine": "img/link-utili/icona.png"` usa un'immagine locale sotto `public/img/`, al posto dell'icona SVG scelta con `icona`. Sono ammessi PNG, SVG, ICO e WebP con nomi semplici e sottocartelle; URL esterni e percorsi che risalgono le directory sono rifiutati. Il percorso base dell'installazione viene aggiunto automaticamente.

L'esempio include l'icona ufficiale di Cedro, distribuita con licenza MIT: vedere `docs/licenze/cedro-MIT.txt`. Le icone degli altri prodotti utilizzati dalla propria organizzazione possono essere aggiunte localmente, rispettandone le condizioni d'uso; non sono necessarie alla demo di esempio.
