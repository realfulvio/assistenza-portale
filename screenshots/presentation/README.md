# Immagini per la presentazione

In questo repository le schermate sono **segnaposto neutri** («Schermata non inclusa»): le schermate reali della demo contengono dati dell'installazione e non vengono distribuite.

Per rigenerarle sulla propria installazione: avvia la demo locale (`DEMO=1 node src/server.js`), apri `http://127.0.0.1:3000/assistenza/` e sostituisci i file con ritagli della tua demo, mantenendo gli stessi nomi e le stesse dimensioni.

| File | Contenuto previsto |
|---|---|
| `01-scelta.png` | Scelta del problema, con tutte le categorie visibili |
| `02-descrizione.png` | Ritaglio del modulo compilato con una segnalazione inventata |
| `03-invio.png` | Conferma dell'invio nel backend simulato |
| `04-elenco.png` | Elenco delle richieste di esempio, filtro Tutte |
| `05-dettaglio.png` | Richiesta In lavorazione e aggiornamento sintetico |
| `06-mobile.png` | Dettaglio della richiesta a larghezza mobile |
| `banner.png` | Titolo e composizione dei ritagli desktop e mobile |
| `percorso.png`, `percorso-mobile.png` | Quattro passaggi, illustrati con ritagli di richieste diverse |
| [ruolo-glpi.png](ruolo-glpi.png) / [sorgente SVG](ruolo-glpi.svg), [versione mobile](ruolo-glpi-mobile.png) | Diagramma esplicativo, non uno screenshot GLPI (incluso) |

Le immagini sono distribuite con il progetto sotto **EUPL-1.2**.
